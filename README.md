# 六级练习室

面向 CET6 听力、阅读、翻译和作文的静态学习网站。入口为 `index.html`，无需构建。

包含 2021 年 12 月至 2026 年 6 月的 36 个真题条目（12 个考期），其中 21 个提供来源原音入口，5 个为写译题页及共用卷；另有 12 组原创听力、12 篇原创翻译、10 道原创作文与专项方法。

真题通过来源网站的页面、PDF链接和原音播放器提供，需要联网。不同来源的套号可能不同，参考译文和范文不是唯一答案。原创训练与真题分别标注。

## 记录与更新

答案、译文、作文、笔记和复习进度仅保存在当前浏览器。“我的复习”支持导出与合并导入。换域名或设备不会自动迁移浏览器记录。

- `papers.js`：真题索引与来源信息。
- `answer-keys.js`：36 个条目的听力、阅读参考答案及同卷来源；共用题型明确标注。
- `objective.js`：客观题选项校验、交卷快照、判分与导入合并。
- `content.js`：原创练习与方法。
- `exams-ui.js`：真题阅读和作答界面。
- `app.js`、`style.css`：主程序与样式。
- `l01.m4a` 至 `l12.m4a`：原创合成听力音频。

保持已有题目 ID 稳定即可保留用户对应练习记录。网站没有服务器数据库，也不提供虚构的自动作文评分。

## GitHub Pages

使用公开仓库，将这些文件放在根目录。在仓库 Settings → Pages 选择 Deploy from a branch，选择 main 分支和 / (root) 后保存。`.nojekyll` 禁用不需要的模板处理。后续向同一发布分支更新文件即可更新网站。

迁移准备日期：2026-09-22。实际发布状态以 GitHub Pages 显示为准。

## 客观题自动判分（2026-10-20）

进入「近五年真题」并打开套卷，选择「听力」或「阅读」。阅读按选词填空 26–35、长篇匹配 36–45、仔细阅读 46–55 分区；匹配选项按原卷实际段落范围提供，允许重复选段。

36 个套卷条目均接入听力25题、阅读30题的第三方参考答案。包含来源明确的共用题型，不能视为36套互不重复试题。仅保存答案字母、选项范围、核验日期和来源链接，不镜像第三方题文与音频。

交卷后显示答对题数、正确率、阅读各题型成绩、错题与未答题。漏答交卷会先提示，未答题保留在分母；未核验题型不评分。成绩仅为练习正确率，不换算官方710分成绩。参考答案并非官方认证答案，遇到疑问可打开同卷来源复核。

成绩保存提交时的答案快照；修改答案后标记待重交。重做保留上次成绩和其他草稿，可撤销；新交卷会替换本模块上次成绩。导入保留本机已有选项，合并缺失作答，重新核算成绩，不信任导入的分数。仍使用原有本地存储键，旧记录兼容。

验证：`node --test tests/objective.test.cjs`。发布无需构建，继续使用 main 分支根目录。
